# 🎓 سیستەمی گروپ چاتی گفتووگۆ و زانست (Seereen Group Chat)

سیستەمێکی پێشکەوتووی گروپ چات بە تەکنەلۆژیای کاتی ڕاستەقینە (Real-time WebSockets & Node.js)، تایبەت بە گفتووگۆی قوتابیان و بەڕێوەبردنی ئەدمین و سوپەر ئەدمین.

---

## 🌟 تایبەتمەندییە سەرەکییەکان

### ١. پلەکان و دەسەڵاتەکان
- **سوپەر ئەدمین (Super Admin 👑):**
  - دەسەڵاتی تەواوی بەدەستە.
  - پەسەندکردن (قبوڵکردن) یان ڕەتکردنەوەی خۆتۆمارکردنی بەکارهێنەرانی نوێ لە بەشی بەڕێوەبردن.
  - گۆڕینی پلەی قوتابی بۆ ئەدمین یان دابەزاندنی ئەدمین بۆ قوتابی.
  - بلۆککردن و لادانی بلۆکی بەکارهێنەران.
  - سڕکردنی خوێندکاران و دانانی پرسیار.
- **ئەدمین (Admin 🛡️):**
  - توانای سڕکردنی خوێندکار (Mute) بۆ ماوەی **٢٤ کاتژمێر** بەجۆرێک کە لەو ماوەیەدا نەتوانێت پەیام بنێرێت (لەگەڵ کاتژمێری ژماردنی پێچەوانەی زیندوو).
  - توانای دانانی پرسیاری فێرکاری لەناو گروپ چاتەکە.
  - هەڵسەنگاندن و پێدانی ئەستێرە بەو قوتابییەی وەڵامی دروست دەداتەوە.
  - سڕینەوەی پەیامە نەشیاوەکان.
- **قوتابی (Student 🎓):**
  - کاتێک کەسێک خۆی تۆمار دەکات، وەک قوتابی دەچێتە حاڵەتی "چاوەڕوانی پەسەندکردن".
  - بەبێ قبوڵکردنی سوپەر ئەدمین ناتوانێت بچێتە ژوورەوە.
  - دوای قبوڵکردن بەشدار دەبێت لە گفتووگۆ و وەڵامدانەوەی پرسیارەکان.
  - خاوەنی باجی ئەستێرە و ژمارەی خاڵە لە تەنیشت ناوەکەی لە چات و لیستی ئەنداماندا.

---

### ٢. سیستەمی ئەستێرە و پلەبەندی (Star Level System)
- هەر وەڵامێکی دروست = **١ خاڵ**.
- لە تەنیشت ناوەکەی هێمای ئەستێرە و ژمارەکە دەردەکەوێت (وەک `⭐ 1/10` تا `⭐ 9/10`).
- **کاتێک گەیشتە ١٠ وەڵامی دروست:**
  - دەبێتە **دوو ئەستێرە** (`⭐⭐`).
  - ژمارەکە سەرلەنوێ لە سفر و یەکەوە دەست پێدەکاتەوە تا دەگاتە پلەی سێ ئەستێرە (`⭐⭐⭐`)، و بەم شێوازە بەردەوام دەبێت.
- تابلۆی ڕێزبەندی (Leaderboard 🏆) زیرەکترین قوتابییەکان بەپێی ئەستێرەکانیان پیشان دەدات.

---

### ٣. پرسیاری تایبەت لە چاتدا
- پرسیاری ئەدمین بە ڕەنگ و دیزاینێکی بریقەداری جیاواز (Golden Glow) و باجی تایبەت لە چاتدا پیشان دەدرێت.
- تاگی ئۆتۆماتیکی `@هەمووان` دەکرێت بۆ ئەوەی هەموو ئەندامان ئاگادار بن.
- دەتوانرێت وەڵامی دروست بە خۆکاری دیاری بکرێت یان ئەدمین بە دەستی کرتە لەسەر پەیامی وەڵامی دروست بکات و ئەستێرە ببەخشێت.
- یاری ئاگرینی ئەستێرەکان (Star Confetti & Audio Fanfare) بەشێوەی زیندوو پەخش دەبێت کاتێک ئەستێرە دەبەخشرێت.

---

### ٤. خۆتۆمارکردن و بەشی بەڕێوەبردن
- فۆڕمی خۆتۆمارکردن بۆ قوتابیان بە ناوی سیانی، ناوی بەکارهێنەر و وشەی نهێنی.
- بەشی بەڕێوەبردنی تایبەت بە سوپەر ئەدمین بۆ بینینی داواکارییە هەڵپەسێردراوەکان، قبوڵکردن یان ڕەتکردنەوە، و بەڕێوەبردنی تەواوی بەکارهێنەران.

---

## 🚀 شێوازی کارپێکردن

### هەژماری سەرەتایی سوپەر ئەدمین:
- **ناوی بەکارهێنەر:** `admin`
- **وشەی نهێنی:** `admin`

### هەنگاوەکانی کارپێکردن:
لە تێرمیناڵ یان PowerShell لە فۆڵدەری پڕۆژەکەدا بنووسە:
```bash
node server.js
```
یان
```bash
npm start
```

پاشان لە وێبگەڕەکەت (Chrome یان Edge) ئەم لینکە بکەرەوە:
👉 **http://localhost:4000**
